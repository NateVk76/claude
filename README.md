# AthletiCards

Jeu de cartes à collectionner sur les sportifs : ouvre des boosters, complète ta collection, échange au mercato
et affronte d'autres équipes en match.

**Jouer : https://paullarose123-ctrl.github.io/AthletiCards/**

Le jeu se trouve dans [`sportmasters/`](sportmasters/) (React + Vite) : voir son [README](sportmasters/README.md)
pour le lancer en local. Les photos viennent de Wikimedia Commons, sous licences libres ; leur auteur est crédité
dans la fiche de chaque carte.
